# Steven & Ashley's Asheville Guide

A mobile-friendly Asheville weekend guide created for guests attending Steven & Ashley's wedding in Asheville, North Carolina.

The guide includes:

- Wedding and after-party logistics
- Asheville neighborhood orientation
- Coffee, brunch, lunch, and dinner recommendations
- Gluten-free, vegetarian, and vegan-friendly indicators
- Local breweries
- Cocktails, rooftops, live music, and dessert
- Couple favorites and Shellie's personal recommendations
- Asheville activities, including the Blue Ridge Parkway, River Arts District, Biltmore Estate, Biltmore Village, wellness, shopping, and art

## Website

This is a static, single-page website. All styling and site assets needed for the guide are contained in `index.html`.

## GitHub Pages Setup

1. Upload the guide HTML file to this repository and name it `index.html`.
2. Upload this `README.md` file.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Click **Save**.

GitHub will publish the site and provide the public URL.

## Updating the Guide

To update the site, replace or edit `index.html` and commit the change. GitHub Pages will automatically publish the new version.
